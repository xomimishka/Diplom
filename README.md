# ShortLinks — сервис коротких ссылок (ВКР)

Веб-приложение для создания, управления и анализа коротких ссылок с QR-кодами, статистикой переходов и системой пользователей.

---

## Технологии

- Frontend: React
- Backend: Node.js (Express)
- Database: PostgreSQL 16
- Инфраструктура: Docker

---

## Запуск проекта (локально)

### 1. Требования

Для запуска проекта необходимо установить:
- Docker
- Docker Compose

---

### 2. Клонирование репозитория

```bash
git clone https://github.com/xomimishka/Diplom.git
cd Diplom
```

## Инструкция по использованию

Запуск проекта:
```bash
docker-compose up --build
```

После запуска проекта:

1. Откройте интерфейс по адресу:
   http://localhost:3000

2. Авторизуйтесь или зарегистрируйтесь в системе

3. Вставьте длинную ссылку в поле ввода

4. Нажмите кнопку "Создать"

5. Система сгенерирует:
   - короткую ссылку
   - QR-код
   - статистику переходов (после кликов)

6. Для перехода используйте короткую ссылку вида:
   http://localhost:5000/r/xxxxx
